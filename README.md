# PVJets SDR Onboarding

Mini-sito di onboarding interattivo per nuovi SDR di PVJets.

- **Target**: nuovo SDR PVJets al primo giorno
- **Formato**: 11 moduli con lezioni brevi + mini-quiz + flashcard
- **Lingua**: bilingue IT / EN
- **Stack**: Next.js 15 + MDX + Tailwind v4, statico, deploy su Vercel
- **Persistenza**: solo `localStorage`, nessun backend
